Задача

Обновить климат без выселения

Старые сплиты и одна приточка на всё здание: летом в переговорных +28 °C, арендаторы уходили. Работать можно было только ночами и по выходным, этаж за этажом.

  • Арендаторы на всех этажах во время работ
  • Нет места под новые шахты
  • Учёт холода по каждому арендатору
Решение

VRF по этажам и одна диспетчерская

Поставили VRF с учётом потребления по арендаторам и поэтажные приточно-вытяжные установки с VAV. Все системы вывели в одну диспетчерскую для службы эксплуатации.

  • Работали ночами, этаж сдавали к утру понедельника
  • Трассы провели в существующих шахтах
  • Счета за холод выставляются по факту потребления
